Countywide PRTG Monitoring & Network Operations Center Initiative

Organization: Charlotte County Board of County Commissioners

Technologies: PRTG Network Monitor, HTML, CSS, JavaScript, SVG, infrastructure monitoring, geographic equipment mapping

Project Type: Countywide infrastructure initiative with individual ownership areas and collaborative development

Project Overview

One of my most significant infrastructure-related contributions has been participating in the organization and development of a countywide PRTG monitoring environment and Network Operations Center (NOC) display system.

The initiative provides centralized visibility into infrastructure health across a geographically distributed county environment. The monitoring platform encompasses server infrastructure, network equipment, wireless access points, power systems, and environmental monitoring equipment.

The project combines structured equipment organization, centralized monitoring, custom dashboard visualization, and geographic mapping to help IT personnel understand infrastructure status and identify the physical locations of monitored equipment.

Infrastructure Scale

  • Approximately 370 servers.
  • Approximately 1,200 network devices.
  • Approximately 8,500 PRTG monitoring sensors.
  • Eight dedicated portrait-oriented 4K displays forming the primary NOC monitoring wall.
  • A separate ninth display dedicated to countywide geographic equipment mapping.

My Primary Responsibilities

My primary area of responsibility within the PRTG environment has been organizing and structuring the monitored equipment. This involved establishing logical equipment organization and improving how infrastructure is represented within the monitoring platform.

  • Held primary responsibility for organizing and structuring monitored equipment throughout the PRTG environment.
  • Organized monitoring visibility across servers, switches, wireless access points, UPS systems, and environmental monitoring equipment.
  • Worked with the equipment organization necessary to support centralized monitoring and the NOC visualization initiative.
  • Independently handled the geographic mapping and physical location organization of monitored equipment for the separate ninth display.
  • Organized equipment location information to support a geographic representation of county infrastructure.

Dashboard Development Contributions

In addition to equipment organization, I contributed to the development of custom PRTG dashboard views. These dashboards use web technologies to provide customized visual representations of infrastructure and monitoring status.

  • Contributed to dashboard development using HTML, CSS, JavaScript, and Scalable Vector Graphics (SVG).
  • Worked with visual representations of infrastructure components, including servers, switches, routers, access points, and UPS systems.
  • Contributed to status-based visual indicators representing healthy, warning, and critical monitoring conditions.
  • Helped develop dashboard layouts designed for continuous display on large-format 4K televisions.

Collaborative NOC Display Initiative

The primary NOC wall consists of eight portrait-oriented 4K displays organized to provide continuous visibility into different areas of the county's infrastructure. The display layout and dashboard development were collaborative efforts.

A separate ninth display was established for the geographic PRTG map. My responsibility for organizing the monitored equipment's physical locations and geographic representation was independent of the collaborative dashboard development work.

Project Impact

The initiative brings together equipment organization, centralized monitoring, custom visualization, and geographic infrastructure representation within one monitoring environment.

The combination of equipment-focused dashboards and a countywide geographic view provides IT personnel with additional context when reviewing infrastructure health and identifying the locations of monitored equipment.

My primary ownership has been equipment organization and geographic mapping. Dashboard development and the overall eight-display NOC initiative involved collaborative contributions.

HR New User Ticket Creation Application

Technologies: PowerShell, Windows Presentation Foundation (WPF), Active Directory, Outlook

Project Type: Independently developed working proof of concept

Project Overview

Developed a graphical application concept designed to streamline the collection of new-hire information and preparation of IT service requests using information provided by Human Resources.

New-user provisioning requires accurate employee information before IT can begin account creation and configuration. Collecting this information through manual processes can introduce inconsistencies and require additional communication between HR and IT.

The application provides a structured graphical interface for collecting employee information and preparing a standardized ticket request.

Application Development

  • Developed a Windows Presentation Foundation graphical interface using PowerShell.
  • Incorporated Active Directory lookups to retrieve existing employee information.
  • Implemented autocomplete functionality for employee titles and manager information using directory attributes.
  • Incorporated support for new-hire and rehire ticket workflows.
  • Implemented Outlook draft generation to prepare the completed request for submission.
  • Included standardized employee information collection to support downstream account provisioning.

Integration & Workflow

The application combines PowerShell, WPF, Active Directory, and Outlook to connect information gathering with IT ticket preparation.

Directory lookups help populate applicable organizational information, while the graphical interface provides a consistent way to collect and review the information required for the request.

Once the information is entered, the application prepares an Outlook email draft containing the ticket details. This provides a more structured handoff between HR and IT without automatically submitting the request.

Development Status & Objective

The working proof of concept demonstrates the core application functionality. Further review and refinement with HR are intended to help determine the next steps for operational use.

The project demonstrates my ability to develop graphical administrative applications and integrate directory services with existing enterprise communication workflows.
